# Так и назвали

Сайт про необычные названия Беларуси: 94 места на карте, гостевые отметки о поездках, оценки, отзывы, комментарии и паспорт путешественника. Регистрация не нужна.

## Публикация в Cloudflare

[Разместить в Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2FFlinch1137%2Ftak-i-nazvali)

Используются только Workers и база D1. R2 и платёжный метод для хранения фотографий не нужны: публикация фото пока недоступна. В форме и вкладке фотографий показана заглушка «Пока недоступно». API также отклоняет загрузки фото.

В настройках Workers & Pages → свой Worker → Settings → Builds укажи:

- Build command: `npm run build`
- Deploy command: `npm run deploy`

Команда публикации находит существующую D1 по имени из wrangler.json или создаёт её, сохраняет настоящий ID, применяет миграции и публикует Worker. Существующие записи не удаляются. Для сборки нужен Cloudflare API token с правами на Worker и D1. В CI скрипт не запускает интерактивный вход.

После запуска проверь адрес workers.dev в приватном окне: карта → место → «Я здесь был» → запись → перезагрузка → «Мой паспорт» → удаление своей записи.

## Запуск с компьютера

Нужен Node.js 22.13+:

```sh
npm ci
npm run setup
```

Скрипт предложит вход в Cloudflare, подготовит D1 и опубликует сайт. Токены не надо вставлять в код или отправлять в чат. Фото временно отключены.

## Последующие обновления

После первого запуска сохрани **обновлённый** `wrangler.json` с настоящим ID базы в GitHub. Там нет паролей или токенов.

В Cloudflare можно подключить автоматическую публикацию к репозиторию через Workers & Pages → свой Worker → Settings → Builds. Имя Worker должно соответствовать полю `name` в `wrangler.json`. Команда сборки: `npm run build`; публикации: `npm run deploy`.

Либо публикуй вручную:

```sh
npm run deploy
```

## Проверка и локальная разработка

```sh
npm ci
npm run check
npm test
npm run deploy:check
npm run dev
```

`npm run dev` применяет миграции только к локальной базе и запускает Wrangler. Локальные тесты используют отдельную базу и хранилище в памяти. `deploy:check` собирает Worker без публикации и без входа в аккаунт. Для местного просмотра открой адрес, напечатанный Wrangler.

## Как устроен проект

- `public/` — сайт, стили, Leaflet и каталог мест.
- `src/index.ts` — Worker, маршрутизация API и статических файлов.
- `src/community.ts` — гостевые публикации и рейтинги и удаление собственных записей.
- `src/catalog.json` — допустимые ID мест для серверной проверки.
- `migrations/0001_community.sql` — схема базы, применяемая Wrangler один раз.
- `wrangler.json` — настройки Cloudflare. Нулевой UUID в исходной версии — явный шаблон; мастер Cloudflare или `setup` заменит его настоящим.
- `scripts/setup.mjs` — первоначальная настройка и запуск.
- `tests/community.mjs` — интеграционные проверки Worker и D1 без R2.

Если меняешь каталог, обновляй и `public/data.json`, и `src/catalog.json`. ID существующих мест должны сохраняться.

## Что важно знать

- Эта папка содержит код и каталог, **не выгрузку уже опубликованных пользовательских отзывов или фотографий**. Новый запуск создаёт свою базу. Предыдущий сайт продолжает работать отдельно.
- В этой версии аккаунтов нет. Cookie браузера позволяет управлять собственными публикациями. После удаления cookies доступ к управлению потеряется. Между разными доменами cookies не переносятся.
- Посещение указывается самим пользователем, а не подтверждается GPS. Рейтинг считает одну актуальную оценку гостевого браузера на место. Повторный визит не увеличивает число уникальных гостевых браузеров.
- Действует ограничение частоты публикаций для гостевого браузера. Проверяются поля публикации и серверное право удаления записи; фото отклоняются. Полноценной модерации и защиты от массового создания новых гостевых браузеров пока нет.
- Загрузка фотографий временно отключена. Не публикуй чужие личные данные в тексте.
- Бесплатные квоты не означают отсутствие оплаты при росте проекта. Проверь условия [Workers](https://developers.cloudflare.com/workers/platform/pricing/), [D1](https://developers.cloudflare.com/d1/platform/pricing/) в своём аккаунте. Код не включает платный план автоматически.
- Дорожные указатели в дизайне остаются декоративными иллюстрациями; точное оформление реальных белорусских знаков требует отдельной правки.
- Своего домена не требуется: можно начать с адреса Cloudflare `workers.dev`.

## Антиспам и модерация

Панель владельца открывается по адресу `/admin`. Посетителям регистрация не нужна. До задания пароля вход в панель закрыт; общего или встроенного пароля нет.

### Включение панели владельца

В Cloudflare: Workers & Pages → tak-i-nazvali → Settings → Variables and Secrets → Add. Создай **Secret** `ADMIN_PASSWORD` — уникальный случайный пароль от 20 до 256 символов, лучше 32 символа из менеджера паролей. Сохрани и примени изменение в Cloudflare. Не добавляй пароль в GitHub, файлы проекта или чат. В `/admin` используй этот пароль. Вход действует 8 часов, выход отзывает сессию; смена пароля делает старые сессии недействительными.

В панели есть очередь жалоб, все записи и скрытые записи, страницы по 50 записей, заметки и журнал действий. Доступны скрытие/восстановление записи, закрытие жалоб, блокировка/разблокировка гостевого браузера автора. Скрытая запись не участвует в публичных рейтингах и посещениях, остаётся в паспорте автора с пометкой. Блокировка запрещает новые записи и жалобы из этого браузера; старые записи скрываются отдельно. Автор может удалить свои записи даже после блокировки. Жалобы сами по себе не скрывают публикацию. Текст жалобы доступен только владельцу. Записи и журналы не удаляются при обновлении.

### Включение Turnstile

Лимиты и модерация работают сразу. Проверка Turnstile **ещё не активна**, пока не заданы ключи:

1. Cloudflare → Turnstile → Add widget. Выбери Managed и разреши текущий hostname `tak-i-nazvali.flinch1137.workers.dev` (без протокола и пути). При смене домена добавь и новый hostname.
2. В Settings → Variables and Secrets своего Worker добавь `TURNSTILE_SITE_KEY` (тип Text, публичный ключ) и `TURNSTILE_SECRET_KEY` (тип Secret, приватный ключ). Примени изменения в Cloudflare.
3. Открой форму отзыва и форму жалобы: дождись проверки и отправь запись. В панели владельца отображается, заданы ли оба ключа; это не заменяет проверку публикации на настоящем домене.

Сервер проверяет токен через Siteverify, а также hostname и действие `publish`/`report`. Без токена, при сбое проверки или при настройке только одного из ключей новые записи и жалобы не принимаются. Не используй тестовые ключи в рабочем сайте. `keep_vars: true` сохраняет заданные в панели переменные при следующем обновлении из GitHub; секреты в репозитории отсутствуют.

### Действующие ограничения

- До 5 новых публикаций в минуту на браузер и 15 попыток за 10 минут на сеть; одинаковая повторная публикация возвращает прежнюю запись. Одновременные повторы защищены уникальным индексом базы.
- До 20 созданий гостевых сессий за 10 минут на сеть. До 5 жалоб за 10 минут на браузер и 10 попыток за 10 минут на сеть; одна жалоба от браузера на запись.
- До 5 попыток входа владельца за 15 минут на сеть. Ответ 429 включает `Retry-After`.
- Сетевой лимит использует доверенный заголовок Cloudflare `CF-Connecting-IP`. В базе сохраняется HMAC адреса с отдельной случайной солью, а не исходный IP. При общих Wi-Fi/VPN лимит может затронуть нескольких людей. Счётчики истекают и периодически очищаются.
- Тело формы читается с ограничением 16 КиБ даже без `Content-Length`; для жалобы — 8 КиБ, для входа и действий владельца — 4 КиБ. Ошибки формы возвращают 400/413.
- Проверяются Origin и права на каждое изменение; cookie владельца — Secure, HttpOnly, SameSite=Strict. Добавлены CSP и запрет встраивания сайта в iframe.

Гостевой режим не подтверждает личность или реальное посещение места. Смена браузера позволяет обойти блокировку гостя; сетевые лимиты и Turnstile дополняют её, но не дают абсолютной защиты от распределённого спама и накрутки. Предложения новых мест, редактирование записей, фотографии и восстановление гостевого доступа после очистки cookies остаются следующими этапами.

`npm test` проверяет гостевые сценарии, ограничения, жалобы, права владельца, скрытие и восстановление рейтинга, блокировку, отзыв сессии и проверку Turnstile. Ответы Siteverify в интеграционных тестах моделируются локально; после задания настоящих ключей нужна проверка на рабочем домене.

## Краткие справки и удобство каталога

У всех 94 мест есть краткое описание и ссылки на источники. Для 26 мест подготовлены дополнительные исторические или природные факты; остальные справки ограничены географией и ближайшей точкой подборки. Текущую численность населения и неподтверждённую этимологию не добавляем. Расстояния между точками — по прямой, а не длина автомобильного маршрута. В карточках рек отмечено, что координаты относятся к устью; точка озера не обозначает пляж или парковку.

На телефоне каталог по умолчанию открывается списком. Пользовательский выбор списка/карты сохраняется в браузере. Leaflet и тайлы карты загружаются только при открытии карты (на большом экране — при приближении каталога к видимой области). Список показывает по 24 записи с кнопкой продолжения; фильтрация и поиск работают по всем 94 местам. Открытие карточки больше не перестраивает весь список и карту. Координаты, источники и соседние точки свёрнуты в раскрываемые блоки. Кнопка маршрута открывает Google Maps; исходная точка выбирается пользователем или самим приложением карт.
